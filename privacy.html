Helmavio — Privacy Policy / Политика конфиденциальности

Last updated: 8 October 2026. Applies to Helmavio 1.1.0 and later.

English

Helmavio is a Windows desktop application. You describe a goal; built-in roles plan, run and verify the work with AI models that you choose. Helmavio has no cloud service, servers or accounts of its own, except the optional Helmavio Pro billing service (section 12).

1. Data stored on your computer

  • Projects (names and folders you add), missions, tasks, agent results, proofs and receipts, the event history and its archive, connection settings, schedules, settings and translation cache.
  • Location: %APPDATA%\Helmavio\data (an existing %APPDATA%\Завод агентов\data profile from earlier versions is used in place). Windows may redirect new Store app data into its package folder. Existing profiles, explicit profile folders and exported files can remain outside that folder.
  • The developer has no access to this data.

2. Data sent to AI model providers you configure

  • When a role or agent runs through a provider you configured — a cloud API (OpenAI-compatible or Anthropic-compatible endpoint), Claude Code CLI (your Claude account), or another server you added — the task text, the mission context and the project files the task needs are sent to that provider, under its terms and privacy policy.
  • Local providers (Ollama on this computer, built-in actions marked "no AI model") send nothing outside your computer.
  • Paid providers are used only when you allow paid usage; the mission contract can forbid paid APIs.

3. Telemetry

  • Helmavio sends no telemetry, analytics, usage statistics or crash reports to the developer or anyone else.
  • "Agent events" shown in the app (for example from Claude Code hooks you register yourself) are written only to the local event log.

4. Logs

  • The app log and the worker log are stored locally (data\logs, data\factory\logs), size-limited. Detected secrets (API keys, tokens, passwords, private keys) are masked before writing.
  • Event-history retention is set by you in Settings; nothing is deleted without your setting.
  • "Create diagnostics" (Settings → Support) saves a local file without goals, project names, results, keys or tokens; it is sent only if you attach it to a support request.

5. Credentials

  • API keys and tokens (model providers, GitHub, Telegram, MCP/A2A connections) are encrypted with Windows DPAPI and decrypted only for the operation you allowed. They are never written to logs, diagnostics, task records or agent prompts.

6. Integrations you control

  • GitHub, Telegram, MCP servers and A2A agents receive data only in calls you allowed (per project, per tool; external calls require your approval of the exact arguments). Remote addresses must use HTTPS. Descriptions and hints from external servers are treated as untrusted data, not instructions.

7. Translation

  • Text in another language (agent answers, service descriptions) is translated locally with Ollama, or by the third-party MyMemory service only after your explicit consent. Code, paths, links, identifiers and detected secrets are replaced with placeholders and are not sent. Nothing from closed or postponed projects or from privacy mode is sent.

8. Generative AI

  • Plans, answers and some checks are produced by generative AI and may be inaccurate. Results are labelled, shown with evidence and an independent Reviewer check. You can report a problematic AI answer from the task card; the report is saved locally (and an e-mail draft opens if a support address is configured).

9. Your choices and deletion

  • You can remove projects, clear the event history, delete keys and connections in the app. Uninstalling the desktop (NSIS) version keeps your data; delete %APPDATA%\Helmavio (and %APPDATA%\Завод агентов, if present) to remove it. Uninstalling the Store version removes package-managed state; existing profiles, explicit profile folders and exports outside the package require separate deletion if you want to remove them.

10. Children

  • Helmavio is a productivity tool not directed at children.

11. Contact

  • Support and privacy questions: ooooooo532@gmail.com. Support page: https://eluz1um.github.io/helmavio-privacy/support.html

12. Helmavio Pro (optional payments)

  • Helmavio Free works without any Helmavio server. The Pro page asks the Helmavio billing service for the Founder licence counter (no personal data is sent; the service sees your IP address).
  • When you buy Pro, the billing service creates an anonymous account (an ID and a recovery key kept in Windows DPAPI) and a random device ID. Payment happens on Stripe Checkout; Stripe processes card details and the billing e-mail under its own privacy policy. Helmavio receives only billing identifiers and statuses (Stripe customer and subscription IDs, plan, period end) — never card data.
  • Helmavio never sends Stripe or the billing service prompts, AI conversations, files, agent results, API keys, MCP credentials or project contents.
  • The app re-checks the plan with the billing service about every 6 hours while online.

Русский

Helmavio — приложение для Windows. Вы описываете цель; встроенные роли планируют, выполняют и проверяют работу с помощью AI-моделей, которые выбираете вы. Своего облака, серверов и учётных записей у Helmavio нет, кроме необязательного сервиса оплаты Helmavio Pro (п. 12).

  1. Данные на вашем компьютере: проекты, миссии, задачи, результаты агентов, доказательства и квитанции, история событий и её архив, подключения, расписания, настройки, кэш перевода — в %APPDATA%\Helmavio\data (существующий профиль %APPDATA%\Завод агентов\data используется на месте). У разработчика доступа к ним нет.
  2. Поставщики моделей, выбранные вами: облачному API, Claude Code CLI (ваша учётная запись Claude) или другому подключённому вами серверу отправляются текст задачи, контекст миссии и нужные файлы проекта — на условиях этого поставщика. Ollama и встроенные действия «без AI-модели» ничего не отправляют наружу. Платные поставщики — только если вы это разрешили.
  3. Телеметрия: не отправляется никакая — ни аналитика, ни статистика, ни отчёты о сбоях.
  4. Журналы: только локально, с ограничением размера; секреты маскируются. «Собрать диагностику» сохраняет локальный файл без целей, названий проектов, результатов, ключей и токенов; он уходит в поддержку, только если вы сами его приложите.
  5. Ключи и токены: шифруются Windows DPAPI, не попадают в журналы, диагностику, записи задач и запросы агентам.
  6. Подключения: GitHub, Telegram, MCP и A2A получают данные только в разрешённых вами вызовах (по проекту, по инструменту, с одобрением точных аргументов). Удалённые адреса — только HTTPS. Описания внешних серверов не считаются доверенными инструкциями.
  7. Перевод: локально (Ollama) или сторонним MyMemory — только с вашего явного согласия, без кода, путей, ссылок, идентификаторов и секретов; закрытые и отложенные проекты и режим приватности не отправляются.
  8. Генеративный ИИ: результаты могут быть неточными; они помечены, сопровождаются доказательствами и независимой проверкой. О проблемном ответе можно сообщить из карточки задачи.
  9. Удаление: удаление версии NSIS сохраняет данные — удалите папку %APPDATA%\Helmavio (и %APPDATA%\Завод агентов, если есть). При удалении версии Store Windows удаляет данные, управляемые пакетом. Старые профили, явно выбранные папки профиля и экспортированные файлы вне пакета могут сохраниться; при необходимости удалите их отдельно.
  10. Дети: приложение не предназначено для детей.
  11. Контакт: ooooooo532@gmail.com — поддержка и вопросы о конфиденциальности. Страница поддержки: https://eluz1um.github.io/helmavio-privacy/support.html
  12. Helmavio Pro (необязательная оплата): Helmavio Free работает без серверов Helmavio. Страница Pro запрашивает у сервиса оплаты Helmavio счётчик лицензий Founder (личные данные не передаются; сервис видит ваш IP-адрес). При покупке Pro сервис создаёт анонимный аккаунт (ID и ключ восстановления, который хранится в Windows DPAPI) и случайный ID устройства. Оплата проходит в Stripe Checkout; данные карты и e-mail для счёта обрабатывает Stripe по своей политике. Helmavio получает только идентификаторы и статусы оплаты (ID клиента и подписки Stripe, тариф, дату окончания периода) — никогда данные карты. Запросы, переписка с AI, файлы, результаты агентов, ключи API, данные MCP и содержимое проектов не передаются ни Stripe, ни сервису оплаты. Пока есть интернет, приложение проверяет тариф примерно раз в 6 часов.
